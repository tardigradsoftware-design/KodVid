# 镜头表：一台摄影机，保持段漏不掉

全片最好只有一个应用窗口。一台摄影机路径下，它从第二场出现，到倒数第二场才淡出，中间**没有任何一次切镜**——换场靠推、拉、摇和顶层文案交接。

这不是省事：一切镜，观众看到的是「一堆截图配了转场」；不切镜，观众看到的是「有人在用这个软件」。

镜头卡切镜路径允许切镜，但**每一镜内部的运镜仍然必须写成带 hold 的镜头表或 PageCam 关键帧**，禁止无保持点的慢漂。PageCam 仍是 2.5D 真实页面镜头的地基。

## 为什么写成镜头表，而不是五条关键帧轨道

后者有一个几乎看不出来、又一定会犯的错：某一条通道漏写一个「保持」关键帧，它就会一路插值穿过整个静止段，让窗口以每帧几百分之一像素的速度漂移。慢到读不出是在动，**却足够让每个字每帧重新反锯齿一次**——画面上就是字在微微发抖，时间轴上看不出任何问题。

`assets/film/src/lib/camera.ts` 里一行是一个镜头，保持段由 `channel()` 自动生成，**漏不掉**：

```ts
const SHOTS: Shot[] = [
  { at: B.files,       move: 0,   px: 780,  py: 440, k: 0.66, cx: 1250, cy: 560 },
  { at: B.files + 55,  move: 55,  px: 780,  py: 440, k: 0.72, cx: 1250, cy: 560 },
  { at: B.files + 95,  move: 40,  px: 150,  py: 420, k: 1.34, cx: 1300, cy: 580 },
];

export const camera = makeCamera(SHOTS, [
  { at: B.files - 13, v: 0 }, { at: B.files + 23, v: 1 },
  { at: B.cross - 5, v: 1 }, { at: B.cross + 40, v: 0 },
], 28); // 30fps 用 ~28；60fps 用默认 55
```

- `at` 是**到位帧**，`move` 是走位时长 → 这个镜头从 `at - move` 走到 `at`。
- `px/py` 看哪儿（窗口坐标）、`k` 多近、`cx/cy` 这个点落在**屏幕**哪儿。
- 把落点写进轨道，是为了给文案留位置：取景的那一栏被推到文案的另一侧。

## 改镜头时必须自己算一遍的事

放大到 `k > 1` 时窗口比画面宽，空地在哪取决于取景点：

- 靠窗口**左**缘的栏 → 空地在**左** → 文案放左。
- 靠窗口**右**缘的栏 → 空地在**右** → 文案放右。
- 中间的东西 → 两侧都被盖住 → 只能拉远（`k ≤ 0.9`），或把窗口整体推到一边。

窗口左缘的屏幕坐标是 `cx - px·k`，右缘是 `cx + (shellW - px)·k`（`edges()` 直接给这四个数）。文案压到窗口上，就是没算这个。

**窗口里的浮层也要按镜头算一遍。** toast、徽标、气泡贴在面板边缘，镜头一推近就可能被推出画面。挂在面板上的浮层，要么放在镜头对着的那一侧，要么就别贴边。

**摄影机没到位之前文案不能出现。** `enter(f, fps, delay)` 的 delay 是在等镜头停稳。镜头还在走的时候进场的字，观众读不进去。

## 运动模糊

`cam.moving` 在停稳时**恰好为 0**，于是 `filter` 那一行可以整个不写：

```tsx
const blur = cam.moving * 2.2 + arrive * 12;
style={{ filter: blur > 0 ? `blur(${blur}px)` : 'none' }}
```

`filter: blur(0px)` 与 `none` 不是一回事——前者仍然会建一个滤镜层再光栅化一次，静止段落里的字会恒定地糊一点点。

3D / PageCam 路径下文字发糊，先查纹理分辨率链路（aesthetic-rules Q2），别先加 DoF。产品宣传片默认不加手持 shake（Q3）。

## 三条禁令

**① 不做察觉不到的缓慢缩放。** 阈值：每帧位移小于 0.02px 的运动，一律删掉。要让画面「活着」，用入场动画。

**② UI 特写场不给窗口加运镜。** 一屏 13px 的字被 `scale()` 每帧按新的亚像素边界重新光栅化，连起来是整台机器在抖。要动就快速走位到位，然后**停死**。

**③ 背景颗粒不要按成片帧率跑。** 60fps 的颗粒盖在边缘干净的窗口上，读出来是整幅在沙沙抖。降到 20fps（三帧换一格；30fps 成片则两帧换一格）。背景的呼吸/光晕可以留，但要慢到每帧 0.1px 以内——漂的是无边缘的光斑，不是字。

## 抖动校验（每次改完镜头都要跑）

停稳的两帧，窗口区域必须**逐像素完全一致**。不要靠肉眼看「好像没动」。

```bash
# 先出 1:1 静帧（COMP 换成 Composition id，模板片常用 AiflPromo）
# PowerShell: $env:SCALE=1; $env:COMP="Film"; node scripts/frames.mjs 460 461 462 463
SCALE=1 COMP=Film node scripts/frames.mjs 460 461 462 463
node scripts/jitter-check.mjs --crop=600:400:1150:400 460 461 462 463
```

四个哈希必须相同。不同 → 有通道在漂，回去看镜头表。这个 bug 在视频里看是「字有点毛」，在时间轴上看什么都正常，**只有哈希能指认它**。

`crop` 的 `W:H:X:Y` 按要检查的窗口区域填，避开会动的文案层和颗粒层。

批量审构图用半分辨率更快：

```bash
SCALE=0.5 COMP=Film node scripts/frames.mjs 90 180 360 540 720 900 1080
```

Remotion Studio（`npm run dev`）用来拖时间轴看动作；构图审查用出图。
