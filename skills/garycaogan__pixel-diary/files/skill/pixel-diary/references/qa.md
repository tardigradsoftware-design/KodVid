# 质检

## 1. 抽帧自己看

```bash
cd work/xxx && npx hyperframes snapshot --at 0,3,12,30,45,60 --no-end --describe false -o ../../snap
```

逐张看下面这些：

- 第 0 帧有没有标题，角色是不是正好在眨眼。
- 文字有没有溢出卡片。
- 印章、便利贴有没有挡住关键文字。
- 不说话的角色有没有变暗，名牌颜色对不对。
- 立绘重画（image 场景的 redraw）是不是逐块出现的。

## 2. 和原片放在一起比

把原片和成片一起交给能看视频的模型，提示词：

```
你是 B 站视频的质检。视频 A 是原版爆款，视频 B 是我们用同样结构做的复刻样片（换了角色和台词）。请认真听音频、看画面，只挑 B 的问题，用中文回答：
1. 音频：背景音乐好不好听、会不会吵、有没有刺耳的地方，和打字音效的音量平衡；和 A 比差在哪。给具体时间点。
2. 打字音效和文字出现是否同步，频率会不会烦人。
3. 画面：哪些时间点文字太小、元素重叠、留白太空，或者节奏太快来不及读。
4. 角色像素画：观感如何，有没有看着别扭的地方。
5. 和 A 比，B 最影响完播和互动的 3 个问题，按严重程度排序，每个给一句改法。
不要夸，只列问题和改法。
```

改完一轮再问一次，只问上一轮的问题解决了没有、有没有新问题。不要每轮都从头评，那样会一直有新意见，收不了尾。

## 3. 第一轮常见的问题和改法

这些都是真实跑出来的：

| 问题 | 改法 |
| --- | --- |
| 打字音尖、吵 | 改成三角波为主，降到 520Hz 左右，音量 0.05；英文最多每秒 20 个音 |
| 配乐高音刺耳 | 旋律降一个八度，加低通；琶音音量压到很低 |
| 道具看不出是什么 | 在像素上重画，加轮廓、高光和品牌色标记 |
| 开场左边空 | 标题放进窗口里，加一行闪烁的“▶ 开始”提示 |
| 规则卡读不完 | 每句停留按字数加长（中文每字 0.032 秒，至少 1 秒） |
| 印章挡住标签 | 印章压在数字上，不压在标签上 |
| 舞台上的字和对话框重复 | 舞台上放补充信息，或者一个反差梗，不要重复台词 |
| 立绘重画像“扫描加载” | 用 6×6 像素一块的逐块拼出，粗网格 |
| 整体偏冷 | 立绘背景用暖色，和深色舞台形成对比 |
