# 拆对标

目标是回答三个问题：

1. 它为什么火？说的是内核，不是“画面可爱”。
2. 现在还能不能做？
3. 我们照着做的话，A 版保留什么，B 版改哪一个点？

## 1. 拿数据

拿下面这些，写进笔记：

- 标题、简介、时长、发布时间。
- 播放、点赞、评论、收藏、投币、分享。
- 账号粉丝数和投稿数。
- 前 20 条热评，置顶评论单独记一笔。

B 站数据有三种拿法：

- **浏览器页面变量**：在登录过的浏览器里打开视频页，读 `window.__INITIAL_STATE__.videoData`（数据）和 `upData`（账号）。命令行直接请求 `api.bilibili.com` 常被风控，返回 412。
- **页面里请求评论**：`/x/v2/reply/main?type=1&oid={aid}&mode=3&ps=20` 要在页面里用 `fetch(..., {credentials: "include"})` 请求。
- **下载视频**：用 yt-dlp，或者在页面里请求 `/x/player/playurl?bvid=..&cid=..&fnval=16`。后一种拿到 dash 的音视频流，带 `Referer: https://www.bilibili.com/` 下载，再用 ffmpeg 合起来。

## 2. 查同题饱和度

1. 在平台搜索原账号名和选题关键词，记下最近一周同题视频的账号、粉丝、播放和发布时间。
2. 重点看跟风号的转化：播放能拿到，粉丝却不涨，说明观众只是看个新鲜，不认这个号。
3. 读热评里的原话。“又一个××号”“已经见过 N 个了”这类评论一出现，原样复刻的窗口就关了。

实际案例（2026-10-20 统计，原片发布约两天后）：

- 原片「Claude大小姐在运营」Day 0：33 万播放，2706 条评论，3 条视频涨到 2.27 万粉。
- 48 小时内，跟风号的 Day 0 拿到 1.1 万到 3.9 万播放，但粉丝只有几百。
- 热评里已经有人在数“见过 3 个 Claude 小姐的号和 6 个大肥鱼的号”。

## 3. 抽帧和听声音

```bash
ffmpeg -i day0.mp4 -vf "fps=1/2,scale=480:-1,tile=4x3" -q:v 3 sheet_%02d.jpg
```

用 Whisper 转写一遍。如果结果是“字幕志愿者”“作曲 某某”这类和画面无关的句子，说明没有人声，台词全在画面上，要从抽帧里读。

## 4. 逐镜头分镜表

把视频交给能看视频、也能听声音的模型（例如 Gemini），用这段提示词：

```
你在拆解一条 B 站爆款视频（N 秒）。请用中文，按时间顺序输出：
1. 音频设计：有没有人声配音？背景音乐风格、打字音效、转场音效、强调音效分别在哪里出现。
2. 逐镜头分镜表：时间码 | 画面（UI 元素、角色表情/动作）| 对话框台词完整原文 | 音效/音乐变化 | 这一镜的作用（钩子/设定/规则/反差/互动/结尾）。台词尽量逐字还原。
3. 角色表情和动作变化有几种，各在什么时候切换。
4. 动画手法：打字机速度、元素入场方式、盖章、进度条等。
5. 整体节奏：多少秒换一个信息点。
```

## 5. 判断内核

按这几个问题逐条写下来：

- **选题**：这个选题自带什么好奇心或冲突？比如“AI 真的在运营账号吗”。
- **人设**：它借了哪个观众已经熟悉的梗或形象？比如 B 站已有的 AI 拟人梗。
- **连载钩子**：有没有让人想追下一集的东西？比如 Day N、公开账本、等级、评论区点菜。
- **互动设计**：评论区能不能直接变成下一期的内容？比如 Day 1 拍的就是 Day 0 点赞最高的那条评论。
- **制作**：最后才看。成本低的形式说明门槛低，跟风会很快。

## 6. 定 A/B

- **A 版**：事件链和原片一一对应，角色、配色、台词换成自己的。
- **B 版**：在 A 的基础上只改一个变量。可以改人设关系（单人改双人）、赌注（加入真实的钱和数据），或者题材（从“运营账号”改成“做一件真实的工作”）。

两版都出片，再拿数据说话。
