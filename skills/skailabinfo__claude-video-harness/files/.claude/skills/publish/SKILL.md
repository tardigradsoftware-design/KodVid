# Публикация через Buffer

Нужен подключённый Buffer MCP (`harness.config.json` → `integrations.buffer: true`, авторизация через `/mcp`). Если инструментов Buffer нет — скажи, как подключить (скилл `setup`, блок 6), и остановись.

1. **Каналы.** `list_channels` → покажи список, спроси, куда публикуем.
2. **Текст.** Из `video/SCRIPT.md` и `captions.json`: первая строка — хук (не повторяй постер дословно), 2–4 строки пользы, призыв из `profile.cta`, хэштеги умеренно (Reels/TikTok 3–5, Shorts — в заголовок). Тон — `profile.tone`. Покажи текст по каждому каналу на правку.
3. **Видео.** Проверь схему `create_post` (`introspect_schema`): Buffer берёт медиа по публичному URL. Если у пользователя есть куда залить `out/final-master.mp4` с публичной ссылкой — спроси ссылку; если нет — создай черновик с текстом, а видео пусть прикрепит в Buffer сам. Не заливай файл никуда без его согласия.
4. **Черновик.** `create_post` с `saveToDraft: true` — по черновику на канал. Дай ссылку/подтверждение.
5. **Публикация / расписание — только после явного «да» в чате** на конкретный пост и время. Одобрение одного поста не распространяется на другие.
